# Пример: Прием и демодуляция FM-станции 90.8 МГц (HackRF One + MathCore.DSP + NAudio)

## Назначение
Документ описывает рабочий демонстрационный сценарий приема широкополосной FM-радиостанции с использованием устройства HackRF One, библиотеки `MathCore.HackRF` для захвата IQ и библиотеки `NAudio` для вывода демодулированного аудио на динамики.

Реализация выполнена в проекте:
- `Tests/ConsoleTest/Program.cs`

## Параметры эксперимента
- Центральная частота приема HackRF: `90_000_000` Гц
- Целевая станция: `90_800_000` Гц
- Частота дискретизации HackRF: `10_000_000` Гц
- Усиление LNA: `24` дБ
- Усиление VGA: `24` дБ
- Длительность захвата в демо: `1` секунда

## Конвейер обработки
1. Захват IQ-потока на 90 МГц
2. Подавление DC-пика (нулевой частоты) методом вычитания скользящего среднего
3. Цифровой гетеродин для сдвига канала `+800_000` Гц в ноль
4. Комплексный ФНЧ и децимация `x25` (`10 МГц -> 400 кГц`)
5. Дробно-рациональный ресемплинг `x12/x5` (`400 кГц -> 960 кГц`)
6. FM-демодуляция + децимация `x10` (`960 кГц -> 96 кГц`)
7. Аудио-ФНЧ + децимация `x2` (`96 кГц -> 48 кГц`) и вывод через NAudio

## Математика этапов

### 1) DC-подавление
Используется одноэкспоненциальная оценка среднего для I и Q:

- `mean_i[n] = mean_i[n-1] + alpha * (i[n] - mean_i[n-1])`
- `mean_q[n] = mean_q[n-1] + alpha * (q[n] - mean_q[n-1])`
- `i_dc[n] = i[n] - mean_i[n]`
- `q_dc[n] = q[n] - mean_q[n]`

### 2) Частотный сдвиг (гетеродин)
Для переноса станции с `+800 кГц` в ноль:

- `x_mix[n] = x_dc[n] * exp(-j * 2*pi * 800000 * n / Fs)`

### 3) ФНЧ + децимация
Комплексный ФНЧ синтезируется оконным методом (Blackman + sinc), затем выполняется децимация `x25`.

### 4) Ресемплинг `12/5`
Реализован рациональный пересчет временной шкалы через sinc-интерполяцию (windowed-sinc) с отношением:

- `Fs_out = Fs_in * 12 / 5`

### 5) FM-демодуляция
Демодуляция через фазовую разность соседних комплексных отсчетов:

- `dphi[n] = arg(conj(x[n-1]) * x[n])`
- `f_inst[n] = dphi[n] * Fs / (2*pi)`

Полученный сигнал фильтруется и децимируется.

## Почему после этапа 6 есть еще x2 децимация
Требование включает децимацию `x10` на этапе демодуляции. После этапа 5 частота равна `960 кГц`, после `x10` получается `96 кГц`.
Для вывода в требуемые `48 кГц` добавлен завершающий аудио-этап `x2`.

## Проверочные метрики (фактический запуск)
На контрольном запуске были получены следующие реперные значения:
- Этап 2: подавление DC порядка `~88 дБ`
- Этап 3: перенос мощности целевого канала из `800 кГц` в `0 Гц`
- Этап 4: `Fs = 400000 Гц`
- Этап 5: `Fs = 960000 Гц`
- Этап 6: `Fs = 96000 Гц`
- Этап 7: `Fs = 48000 Гц`, аудио воспроизводится

## Как запустить
Из корня репозитория:

```powershell
dotnet run --project Tests/ConsoleTest/ConsoleTest.csproj -c Debug
```

## Проверка оборудования
Перед запуском рекомендуется проверить устройство:

```powershell
hackrf_info.exe
```

Ожидается обнаружение HackRF One и корректные версии прошивки/API.

## Перенос на другое рабочее место
1. Подключить HackRF One и убедиться, что `hackrf_info.exe` видит устройство
2. Установить .NET SDK под `net10.0`
3. Выполнить `dotnet restore`
4. Запустить `ConsoleTest` командой выше
5. Сверить этапные метрики с `docs/HackRF-FM-Demo-Tracking.md`

## Замечания
- Для реального эфира уровни и спектр зависят от антенны и RF-обстановки
- При необходимости можно настраивать `LNA/VGA`, длительность захвата и параметры фильтров
- Реализация ориентирована на демонстрационный, но воспроизводимый сценарий с подтверждением на физическом оборудовании
