# Лаборатория БИХ-фильтров (WpfTest)

Демонстрационное WPF-приложение для экспериментального исследования БИХ-фильтров, реализованных в библиотеке `MathCore.DSP`.

## Возможности

- **Синтез фильтров** четырёх типов: ФНЧ, ФВЧ, ППФ, ПЗФ.
- **Реализации**: Баттерворта, Чебышева I и II рода, Чебышева II рода с коррекцией, эллиптический (Золотарёва-Кауэра), RC-цепочка, RC-экспоненциальная, RLC-контур и фильтр из файла коэффициентов.
- **Визуализация в реальном времени** при изменении любого параметра:
  - АЧХ (дБ) и ФЧХ (градусы) на одном графике;
  - импульсная характеристика;
  - групповая задержка в отсчётах;
  - карта нулей и полюсов с единичной окружностью.
- **Сохранение коэффициентов** полиномов `B` и `A` в JSON или текстовый файл.
- **Загрузка коэффициентов** из файла как отдельный вариант фильтра.
- **Аудиоэксперимент**: загрузка WAV/MP3, фильтрация, сохранение результата в WAV и воспроизведение исходного/отфильтрованного сигнала.
- Поддержка перетаскивания аудиофайлов в окно.

## Запуск

```bash
dotnet run --project Tests/WpfTest/WpfTest.csproj
```

Самопроверка синтеза, анализа, сериализации коэффициентов и обработки аудио:

```bash
dotnet run --project Tests/WpfTest/WpfTest.csproj -- --selftest
```

Результат самопроверки записывается в `%TEMP%\MathCore.DSP.WpfTest.selftest.log`, код завершения `0` соответствует успеху.

## Формат файла коэффициентов

Поддерживается JSON:

```json
{
  "format": "MathCore.DSP.IIR",
  "version": 1,
  "samplingFrequency": 10000,
  "description": "Баттерворта · ППФ",
  "b": [0.01967435974186816, -0.01713698421440238, 0.03328989594358543, -0.01713698421440238, 0.01967435974186816],
  "a": [1, -3.0330095397460317, 3.811795174310083, -2.291096732096068, 0.5553569394635934]
}
```

и текстовый формат:

```text
# fd = 10000
B: 0.1 0.2 0.3
A: 1 -0.5 0.2
```

В текстовом формате допускаются комментарии `#` и `//`, разделители — пробелы, табуляция, точка с запятой или запятая (CSV).

## Замечания

- При загрузке аудиофайла частота дискретизации фильтра автоматически приводится к частоте файла, а границы полос масштабируются пропорционально.
- Неустойчивый или некорректно заданный фильтр не ломает интерфейс: сообщение об ошибке выводится в строке состояния, а графики сохраняют последнее корректное состояние.
- Расчёт групповой задержки выполняется по непрерывной ФЧХ; в полосе подавления и в нулях передачи значения не отображаются.
